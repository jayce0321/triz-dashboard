# 뉴스콘텐츠시스템

저작권 무침해 **공공 데이터**를 기반으로, 구글뉴스 노출을 노린
'가벼운 기사 → 심층 분석 기사'를 **매일 자동 제안·생성**하는 시스템.

- **SEO → GEO 전환**: 기사 타입마다 검색(SEO)과 생성형 AI 검색(GEO) 전략을 레지스트리로 관리
- **저작권 안전**: 공공기관 수치 + 구글뉴스 헤드라인(제목만) + matplotlib 자체 생성 이미지
- **실데이터 우선**: 환율(ECB)·코스피(Yahoo)·날씨(open-meteo)는 키 없이 실데이터, `.env`의 ECOS 키 설정 시 금리·물가도 실데이터
- **3가지 인터페이스**: CLI / 웹 대시보드 / GitHub Actions 자동 발행

운영 절차는 [OPS.md](OPS.md) 를 참고한다.

## 폴더 구조

```
뉴스콘텐츠시스템/
├── 뉴스콘텐츠시스템.py      # CLI
├── 대시보드.py              # 웹 대시보드(Flask, :8123)
├── 발행인덱스.py            # 발행 기사 인덱스 생성
├── README.md                # 시스템 개요·사용법
├── OPS.md                   # 운영매뉴얼
├── .env                     # ECOS API 키(환경변수, git 미추적)
├── 설정/
│   ├── config.json          # 브랜드·데이터소스 설정(키는 .env에서 주입)
│   └── 상태.json            # 기사 승인/발행 상태
├── core/
│   ├── 기사타입.py           # SEO→GEO 기사 스펙트럼 레지스트리(6종)
│   ├── 소재수집.py           # 분야별 구글뉴스 RSS 헤드라인 수집(제목만, 저작권 안전)
│   ├── 데이터소스.py         # 공공데이터 수집(환율·금리·물가·지수·날씨)
│   ├── 기사생성.py           # 헤드라인·리드·본문 + json-ld 스키마
│   └── 이미지생성.py         # matplotlib 차트·썸네일(무저작권)
└── 기사발행물/YYYY-MM-DD/    # 생성 산출물
```

## 사용법

```bash
python3 뉴스콘텐츠시스템.py 타입목록                 # 기사 스펙트럼 확인
python3 뉴스콘텐츠시스템.py 후보                     # 오늘의 실시간 소재 후보 제안(구글뉴스 헤드라인)
python3 뉴스콘텐츠시스템.py 생성                     # 기본(수치리포트) 기사 생성
python3 뉴스콘텐츠시스템.py 생성 --type 심층분석     # 타입 지정 생성
python3 뉴스콘텐츠시스템.py 생성 --type 쉬운설명     # 프리머(개념 설명) 생성
python3 뉴스콘텐츠시스템.py 생성 --소재 "폭염 기상 이슈"   # 후보에서 고른 소재로 생성
python3 뉴스콘텐츠시스템.py 기사 수치리포트          # 타입 상세(SEO/GEO 전략)
```

생성 결과는 `기사발행물/오늘날짜/`에 다음이 함께 저장됩니다.

- `*.md` 기사 본문(마크다운)
- `*.json-ld` Google News 구조화 데이터(NewsArticle)
- `이미지/*_차트.png` 데이터 시각화(16:9)
- `이미지/*_썸네일.png` 브랜드 배너(16:9, "jayce's 세계시그널" 브랜딩)

## 실데이터 전환

기본은 시뮬레이션 모드이며, 각 지표는 실데이터가 가능하면 자동으로 우선 사용한다.

| 지표 | 소스 | 키 필요 | 상태 |
|------|------|--------|------|
| 코스피·지수 | Yahoo Finance 공개 | 없음 | 실데이터 |
| 원/달러 환율 | ECB frankfurter 공개 | 없음 | 실데이터 |
| 서울 날씨 | open-meteo 공개 | 없음 | 실데이터 |
| 기준금리 | 한국은행 ECOS (`722Y001`/`0101000`) | 필요 | 실데이터(키 설정됨) |
| 소비자물가 | 한국은행 ECOS (`901Y010`/`00`) | 필요 | 실데이터(키 설정됨) |

실데이터 전환을 위해 (금리·물가만 키가 필요하며, 환율·지수·날씨는 기본 실데이터):

1. 한국은행 경제통계시스템(ECOS) API 키 발급: https://ecos.bok.or.kr → Open API 서비스 → 인증키 확인
2. 프로젝트 루트의 `.env` 파일에 키 입력. `설정/config.json`의 `api_key`는 비워둔다.
   ```env
   ECOS_API_KEY=발급받은키
   ```
   - 전역 환경변수로도 동일 이름(`ECOS_API_KEY`)으로 주입 가능 (GitHub Actions Secret과 동일 방식)
3. (자동) 재생성 시 기준금리·물가가 ECOS 실측 데이터로 전환되고, 기사·대시보드에 "실데이터"로 표기됨
   - 기준금리: 표코드 `722Y001`, 항목 `0101000`
   - 소비자물가: 표코드 `901Y010`, 항목 `00`(총지수, 전년동월 대비 상승률로 자동 계산)

> 🔐 보안: `.env`는 `.gitignore`에 등록되어 커밋되지 않는다. 키를 형상관리 저장소에 올리지 않도록 주의한다.

대시보드 상단 **데이터소스 현황** 패널에서 각 지표가 실/시뮬인지 즉시 확인할 수 있다.

## 웹 대시보드

기사를 브라우저에서 확인·승인·발행하는 관리 화면.

```bash
python3 대시보드.py
# 접속: http://127.0.0.1:8123
```

기능:
- **소재 후보** : 분야별(종합·금융·물가·산업·부동산·환경) 구글뉴스 헤드라인 실시간 수집, 클릭하면 소재 입력칸에 채워짐
- **기사 생성** : 타입·소재 선택 후 한 번에 생성(차트·썸네일 포함)
- **목록·미리보기** : 생성된 기사를 카드로 확인, 본문 미리보기
- **승인/발행/삭제** : 상태(초안→승인→발행)를 `설정/상태.json`에 관리

## 자동 발행(GitHub Actions)

`.github/workflows/news-content-generate.yml` 이 매일 **오전 5시(KST)** 자동 실행되어
`수치리포트` + `테마해설` 기사를 생성하고 발행 인덱스까지 커밋한다.

- `--소재 auto`로 오늘의 실시간 헤드라인을 자동 선택(매일 다른 기사)
- GitHub Secrets > **`ECOS_API_KEY`** 등록 시 기준금리·물가도 실데이터로 전환
- 결과물은 `뉴스콘텐츠시스템/기사발행물/`에 커밋 + 아티팩트 저장
- GitHub Actions 탭 > **Run workflow** 로 수동 실행 가능

### 발행 인덱스

```bash
python3 발행인덱스.py              # 전체 최신 기사 인덱스
python3 발행인덱스.py --상태 발행  # 발행 상태만
```
