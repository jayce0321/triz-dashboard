# 운영매뉴얼 (OPS)

뉴스콘텐츠시스템의 설치·일일운영·문제해결·실데이터 전환 절차를 다룬다.
신규 운영자가 이 문서만으로 시스템을 돌릴 수 있게 작성했다.

---

## 1. 시스템 개요

저작권 무침해 공공 데이터를 기반으로, 구글뉴스 노출용 기사를
"가벼운 기사 → 심층 분석 기사" 스펙트럼으로 자동 생성하는 시스템.

| 구성 | 역할 |
|------|------|
| `뉴스콘텐츠시스템.py` | CLI: 소재 수집, 기사 생성 |
| `대시보드.py` | 웹 관리화면 (Flask, :8123) |
| `발행인덱스.py` | 발행 기사 목록 인덱스 생성 |
| `core/*.py` | 타입·데이터·기사·이미지 로직 |
| `.github/workflows/news-content-generate.yml` | 매일 자동 생성·커밋 |

## 2. 사전 준비 (최초 1회)

### 2.1 필수 환경

- Python 3.10 이상
- 패키지: `matplotlib`, `feedparser`, `requests`, `flask`

```bash
pip install matplotlib feedparser requests flask
```

### 2.2 한국은행 ECOS API 키 (선택, 실데이터용)

기준금리·물가를 실데이터로 쓰려면 키가 필요하다.

1. https://ecos.bok.or.kr → 회원가입 → API 인증키 신청
2. 프로젝트 루트에 `.env` 파일을 만들고 키를 입력한다.
   ```env
   ECOS_API_KEY=발급받은인증키
   ```
   - `.env`는 `.gitignore`에 등록되어 커밋되지 않는다.
   - 전역 환경변수 `ECOS_API_KEY` 로 주입해도 된다 (GitHub Actions Secret과 동일 방식).
   - 키 입력만 하면 대시보드·CLI 모두 자동으로 실데이터로 전환된다.

### 2.3 포인트 컬러·사이트명 변경

`설정/config.json`의 `브랜드` 섹션을 수정한다.

- `사이트명`, `발행도메인` → json-ld·URL에 반영
- `포인트컬러`(`#2367d7`) → 썸네일·차트 색상

## 3. 일일 운영 절차

### 3.1 기본(자동화) 운영

가장 단순한 운영은 GitHub Actions에 맡긴다.

1. 코드를 GitHub에 push
2. 매일 **오전 5시(KST)** 워크플로가 자동 실행
3. `수치리포트` + `테마해설` 기사를 `--소재 auto`로 생성
4. 결과가 `뉴스콘텐츠시스템/기사발행물/`에 커밋됨
5. GitHub Actions 탭 → **Run workflow** 로 수동 실행도 가능

### 3.2 수동(로컬) 운영

```bash
cd 홈페이지_첫버전/뉴스콘텐츠시스템

# 1) 오늘의 소재 확인
python3 뉴스콘텐츠시스템.py 후보

# 2) 기사 생성
python3 뉴스콘텐츠시스템.py 생성 --type 수치리포트 --소재 auto
python3 뉴스콘텐츠시스템.py 생성 --type 테마해설 --소재 "이슈 키워드"
python3 뉴스콘텐츠시스템.py 생성 --type 심층분석

# 3) 발행 인덱스 갱신
python3 발행인덱스.py --상태 발행
```

생성 산출물: `기사발행물/YYYY-MM-DD/` 아래 `.md` + `.json-ld` + `이미지/*.png`

### 3.3 웹 대시보드 운영

```bash
python3 대시보드.py
# 접속: http://127.0.0.1:8123
```

권장 흐름:
1. **오늘의 소재 후보** → 원하는 헤드라인 클릭 (소재 입력칸에 자동 입력)
2. **새 기사 생성** → 타입·소재 선택 후 생성
3. 목록에서 **미리보기** → 내용 검토
4. **승인** → **발행** 순으로 상태 전환
5. 상태는 `설정/상태.json`에 기록

## 4. 데이터소스 상태 판단

| 지표 | 소스 | 키 | 실데이터 조건 |
|------|------|-----|--------------|
| 코스피·지수 | Yahoo Finance | 없음 | 기본 실데이터 |
| 원/달러 환율 | ECB frankfurter | 없음 | 기본 실데이터 |
| 서울 날씨 | open-meteo | 없음 | 기본 실데이터 |
| 기준금리 | 한국은행 ECOS (`722Y001`/`0101000`) | 필요 | `.env` 키 설정 시 |
| 소비자물가 | 한국은행 ECOS (`901Y010`/`00`) | 필요 | `.env` 키 설정 시 |

- **시뮬레이션 표기**: 출처 문자열에 `(시뮬레이션, ...)` 포함
- **실데이터 표기**: 출처 문자열에 `(실데이터)` 포함
- 대시보드 상단 **데이터소스 현황** 패널에서 실/시뮬 즉시 확인
- 시뮬레이션 데이터로 생성된 기사는 **구글뉴스 노출에 부적합**하다.
  발행 전 반드시 실데이터 전환을 확인한다.

## 5. 구글뉴스 노출을 위한 추가 작업 (외부)

이 시스템이 생성하는 것은 "노출될 준비가 된 콘텐츠"다.
실제 구글뉴스 노출은 아래를 충족해야 한다.

1. **웹사이트 배포**: 기사발행물을 정적 사이트(GitHub Pages/Vercel)에 배포
2. **NewsArticle 스키마 유지**: `*.json-ld`를 페이지 `<script type="application/ld+json">`에 삽입
3. **Google 뉴스발행자 센터 등록**: https://news.google.com/publisher
   - 사이트 소유권 확인 → 발행자 신청 → 콘텐츠 정책 검토
4. **신뢰 요소**: 명확한 제작자·연락처·회사 정보, 저작권 정책 페이지
5. **발행 빈도·일관성**: 매일 일정 시간에 발행 (워크플로가 지원)

> ⚠️ 구글뉴스는 자동생성 콘텐츠(AI/대량 생성)에 엄격하다.
> 실데이터 기반의 원본 콘텐츠만 노출 대상이다. 시뮬레이션 기사는 발행 금지.

## 6. 트러블슈팅

### 6.1 "시뮬레이션" 경고가 계속 뜬다
- 환율: ECB frankfurter / 날씨: open-meteo 가 접속 불가일 때 → 네트워크 확인 후 재시도 (키 불필요 공개 API)
- 금리·물가: `.env`에 ECOS 키가 없거나 잘못된 경우 → `.env`의 `ECOS_API_KEY` 확인·발급
- 야후 지수마저 실패: 방화벽/프록시 확인

### 6.2 대시보드가 열리지 않는다
```bash
# 실행 중인 프로세스 확인
pgrep -fl "대시보드"
# 강제 종료 후 재시작
pkill -9 -f "python3 대시보드"
nohup python3 대시보드.py </dev/null > /tmp/dash.log 2>&1 &
# 확인
curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:8123/
```
- 포트 8123 충돌 시 `대시보드.py` 하단 `port=` 변경

### 6.3 파일이 보였다가 사라진다 (macOS iCloud)
- iCloud Drive는 파일을 비동기 동기화하여 순간적으로 안 보일 수 있다.
- 작업 전 `ls` 로 파일 존재를 확인하고, 터미널에서 경로는 복사해서 사용한다.
- NFC/비NFC 유니코드 경로 차이로 파일을 못 찾는 일이 있다.
  워크디렉토리 경로를 `pwd`로 확정한 뒤 사용할 것.

### 6.4 GitHub Actions 생성 단계 실패
- `pip install matplotlib feedparser requests` 가 설치되는지 확인
- ECOS Secret 이름이 `ECOS_API_KEY` 인지 확인
- 로그: Actions 탭 → 실패한 job → Generate daily articles 단계

### 6.5 기사가 같은 소재로 반복 생성된다
- `--소재 auto` 를 쓰면 오늘의 헤드라인으로 자동 교체된다.
- 소재를 직접 지정하면 같은 소재로 중복 생성될 수 있으니,
  날짜별 폴더에서 같은 파일명이면 덮어쓴다는 점에 유의한다.

## 7. 백업·관리

- `기사발행물/`은 git에 커밋되므로 히스토리로 복구 가능
- `설정/상태.json` : 승인/발행 상태 (삭제하면 초안으로 초기화)
- 주기적으로 `발행인덱스.py --상태 발행`으로 발행 목록을 유지
- 외부 DB·사용자 데이터를 다루지 않으므로 보안 민감 정보는 `.env`의 ECOS API 키뿐.
  키는 `.gitignore`에 등록된 `.env`에만 두고 공개 저장소에 커밋하지 않는다.
