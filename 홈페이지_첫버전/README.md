# 홈페이지 첫버전

개인 홈페이지의 첫 버전입니다. 코딩 대시보드 목록과 Hoya Bot 데일리 테제를 한곳에 모아 정적 HTML로 발행합니다.

## 사용법

1. Hoya Bot 데일리 테제 연결은 `호야테제_연결.json`에서 관리합니다.
2. 새 로컬 테제를 보조로 추가하려면 `테제/` 폴더에 Markdown 파일을 넣습니다.
3. 대시보드를 추가하려면 `대시보드목록.json`에 항목을 넣습니다.
4. 아래 명령으로 홈페이지를 다시 생성합니다.

```bash
python3 홈페이지_생성.py
```

생성 결과는 `index.html`입니다.

## 로컬 보조테제 반영

홈페이지 편집 화면에서 `Markdown 다운로드`를 누른 뒤 아래 명령을 실행하면, 가장 최근 다운로드한 Markdown 파일을 `테제/` 폴더로 복사하고 홈페이지를 다시 생성합니다.

```bash
python3 로컬보조테제_반영.py
```

## 자동 발행 구상

GitHub Pages나 Vercel에 올릴 경우, 커밋이 들어올 때 `홈페이지_생성.py`를 실행하도록 설정하면 Hoya Bot 발행 URL과 로컬 테제가 홈페이지에 반영됩니다.

## 조간 브리핑 자동 반영

프로젝트의 당일 조간 브리핑 원문을 `테제/`에 같은 파일명으로 덮어쓰고 홈페이지를 재생성·검증합니다. 같은 날 재실행해도 중복 보조테제가 생기지 않습니다.

```bash
python3 조간브리핑_반영.py
```

특정 원문을 지정할 수도 있습니다.

```bash
python3 조간브리핑_반영.py ../조간-정세-브리핑/2026/07/2026-07-16_조간브리핑.md
```
